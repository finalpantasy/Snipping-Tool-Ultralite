# Dark frosted design review

Scope: two static headless visual studies, capture window and annotation preview, before changing production UI. Use the already-confirmed product interview in PRODUCT.md. User pinned dark, frosted, Apple-like design; that commitment overrides unrelated visual systems. The incumbent large heading, slogan, mint blocks and checkbox card are the anti-reference.

Mode: Operate. Single restrained Segoe UI family, native Windows window controls, graphite tinted surfaces, thin separators, compact toolbar groups, one blue New action. The capture occupies the editor rather than being displaced by marketing or settings. Secondary after-capture options move into Settings; annotation tools beyond the small primary set remain available through overflow. Capture/copy/upload behavior remains as agreed.

Glass is simulated over an authored abstract background in these SVG concepts. A future implementation should use an OS backdrop, never continuously capture and blur the desktop. Windows DWM supports system materials; source: https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type . Native composition has not been proven in the current renderer and must be tested separately.

Skill direction seed run for process compliance. Its unrelated challengers do not preserve the explicit material brief or screenshot-tool familiarity; no challenge replaces the user's pinned direction. This is a proposal for visual approval, not an implementation or UI acceptance pass.

Segoe UI is read from Windows for local review only; no Windows font file is copied or bundled. Icon paths are authored geometry within the concept script. Screenshot content is illustrative, not captured from any desktop. Production source and the portable package remain unchanged in this review.

# Media provenance

The public media was captured from the real Snipping Tool UL 0.3.15 Windows app. The application used a separate recording configuration and an authored fictional project brief. No personal desktop content, account screens, file listings or notifications are included in the published assets.

- `media/home-dark.png`: a native app client-area screenshot.
- `media/editor-dark.png`: a frame from a native editor-window recording after a real region capture and wheel zoom. The app reported that the captured image had been copied to the clipboard.
- `media/Snipping-Tool-UL-demo.mp4`: a 32-second captioned product tour. It combines the real home screenshot, the verified first eight seconds of editor footage, close-up crops of that same interface, and branded title cards. It does not simulate clicks, drawing or other UI actions.
- `media/demo-poster.png`: a title treatment around the real editor screenshot.
- `media/demo.vtt`: the tour's English captions. The video is silent.

Client-area screenshots exclude the native window frame. The screenshots show an actual app using sample content, not a mockup. The tour is an interface overview; it is not evidence of every feature working end to end. Live public uploads and image pasting into external apps were not exercised for this recording.

Older images under `docs/images` remain headless rendering examples used in technical verification. They are separate from the real native media above and should not be described as live workflow screenshots.

# GitHub publication

Repository: `finalpantasy/Snipping-Tool-Ultralite`, public and standalone. Product: **Snipping Tool UL**. Description: **Ultralight native Rust Snipping Tool replacement for Windows 11: clipboard captures, annotations, hotkeys, timers and no-setup image sharing.**

The GitHub README is the product presentation. GitHub Pages and the rejected video are withdrawn at the user's request. Light mode is the default; dark mode remains selectable. Current light pictures are actual app-code renders with fictional samples, clearly labelled and explicitly approved instead of new native screenshots. [Media provenance](MEDIA.md)

Publish as a preview. No verified end-to-end speed comparison, total-app memory promise or universal compatibility claim is made. Preserve upstream MIT and dependency notices. Scan source, package, diff and commit metadata before every push; use the public account handle and GitHub noreply identity.

Native window resizing, capture exclusion, foreground activation, paste into external applications, mixed-monitor DPI, timer/hotkey interaction, live uploads, shell integration and total-app memory/latency remain isolated-session acceptance gaps. Sandbox setup is deferred. Do not run native GUI or capture on the user's working desktop.

# Image sharing service research

Checked 2026-10-12 against official documentation. These are service policies and API capabilities, not live upload or availability test results. Catbox, Freeimage.host and Litterbox are implemented as no-user-key choices in Options > Image host. Other providers below are research only.

## Catbox and the app cooldown

No numeric daily upload quota was found in Catbox's [API documentation](https://catbox.moe/tools.php), [FAQ](https://catbox.moe/faq.php) or [Terms and Acceptable Use Policy](https://catbox.moe/legal.php). That does not mean unrestricted uploads: flooding, spamming and unreasonable load are prohibited, and access can be suspended.

The API supports anonymous uploads without a key. The [homepage](https://catbox.moe/) lists a 200 MB file limit. The current FAQ says anonymous files are removed after **two years with no accesses**, while account-associated files are permanent under its rules. Older search results saying all uploads last forever are stale. The FAQ also documents regional and ISP blocks, so one host will not reach every reader. Commercial projects generating revenue require prior written permission under its terms.

UL now spaces new upload attempts at least five seconds apart, including failed attempts. Only one upload can run at a time. Copying a cached link stays immediate. Confirmation and cancellation do not consume the cooldown, and rejected clicks do not extend it. There are no app-imposed hourly or daily caps, sleeps on the UI thread or queued automatic retries. The cooldown uses a monotonic clock in the running session; restarting or modifying the open-source client can bypass it. Host-side enforcement remains necessary for deliberate abuse.

## Implemented product behavior

Catbox remains the default. Freeimage.host is an explicitly selected alternative with a public-discovery disclosure; Litterbox provides expiring links. Provider choice is in Options > Image host so the ordinary Upload button remains one click. No credential-entry dialog is needed. A failed upload can offer a user-selected alternative; never silently send the same image to several services or rotate hosts to bypass a limit.

Return the original direct PNG URL rather than a thumbnail or gallery link. [RES's actual generic image handler](https://github.com/honestbleeps/Reddit-Enhancement-Suite/blob/master/lib/modules/hosts/defaultImage.js) recognizes PNG, JPEG, GIF, WebP and SVG URL extensions. This supports the expected old-Reddit inline-image behavior when the host is accessible; it does not prove live viewing, subreddit acceptance or a native Reddit image-post preview. Those remain separate tests.

Adapters reuse the existing PNG encoder and HTTP dependency, with bounded replies and strict HTTPS PNG destination checks. No embedded browser, background polling or provider SDK was added. Tests inspect exact request fields and responses without performing uploads. The eight-link cache keys include host and expiry choice, expires temporary links conservatively, and preserves a single five-second cooldown across destinations.

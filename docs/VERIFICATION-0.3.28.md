# Snipping Tool UL 0.3.28: input-method text, Esc cancels a timer, full-pixel redaction

New: the Text tool accepts input-method composition and commits through winit's IME events, with the candidate list placed at the text caret. Characters Open Sans lacks are drawn from Windows system fonts (Yu Gothic, Microsoft YaHei, Malgun Gothic, Segoe UI Symbol, ordered by the user's locale) loaded on first use. The delayed-capture countdown holds Escape as a global key while it runs. JPEG saves composite transparency over white. A tool letter that is already taken swaps between the two tools. Pixelate and spotlight round their box outward to whole pixels. Snip the same area again requires the area to lie on current monitors. The weekly update check retries after a failed request. Pin windows are framed row by row.

## Verification

- 410 locked all-target automated tests pass (2 ignored), 14 more than 0.3.27. New headless tests cover monitor coverage for the repeat area (gaps beside a smaller monitor, an unplugged monitor), outward pixel rounding including float saturation, fractional pixelate and spotlight boxes against their whole-pixel cover, save-name extensions, Settings thickness clamping, the row-wise pin frame against the old three-pass build (byte for byte), JPEG transparency on white, shortcut swapping, fallback glyphs from Yu Gothic or YaHei and Malgun Gothic, a missing fallback font, the full-width space, and composition text that is shown but never committed. Rustfmt is clean and Clippy reports no warning on a changed line.
- Release timing on this PC: building a 4K pin window takes 9.8 ms instead of 41.1 ms. Measuring Latin text is unchanged at 0.6 µs. The first CJK character takes 18 ms to load its font, and each newly used 128-character block takes 18 ms on average (38 ms worst).
- Independent code review of the countdown, IME, font fallback, JPEG and shortcut changes. Its one confirmed defect (an IME full-width space drawn as a box beside kanji) was fixed before release.
- Not verified natively: typing with a real Japanese, Chinese or Korean input method, the Korean IME's Enter after a syllable (it may need a second press), Esc during a countdown, History hover, the update retry, the repeat area after a real monitor change, and second-launch focus. Each needs a live window, network or display change, and the project does not run windows on the working desktop. Mixed-scaling monitors remain untested.
- Remapped Windows build, source and package identity scans, and archive-entry hashes checked before publication.
